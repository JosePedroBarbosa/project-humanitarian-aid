# Humanitarian Aid Distribution System

Academic project developed to support and optimize the distribution of humanitarian aid in emergency scenarios such as natural disasters and humanitarian crises.

The system focuses on managing aid collection points, vehicles, and distribution routes, helping humanitarian organizations organize resources and plan deliveries more efficiently.

---

## ✨ Features

- Management of humanitarian aid collection points
- Organization and tracking of aid containers and supplies
- Route planning for aid distribution vehicles
- Support for different vehicle types and delivery constraints
- Import of external data for realistic simulation
- Generation of reports and distribution summaries

---

## 🛠️ Technologies

- Java
- Object-Oriented Programming
- Data structures and algorithms
- File and API data integration

---

## 🎓 Academic Context

This project was developed as part of the **Software Engineering degree**, with the goal of applying object-oriented design, data structures, and problem-solving techniques to a real-world humanitarian scenario.
